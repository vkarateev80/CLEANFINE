# Переводы интерфейса оператора

Единый словарь для нативного приложения (`mobile/cleaning-ops-app`) и веб-версии
(`frontend/web-operator`). Ключ — русская строка интерфейса как она написана в коде,
значение — перевод. Плейсхолдеры в фигурных скобках (`{n}`, `{name}`) переносятся
в перевод как есть.

- `ky.json` — кыргызский (кириллица);
- `uz.json` — узбекский (латиница, апостроф `ʻ` как в практикуме RU–KY–UZ).

Код берёт перевод по русской строке: в Dart — `tr('Сегодня')` / `'Сегодня'.tr`,
в TypeScript — `t('Сегодня')`. Нет перевода — показывается русский текст.

Проверка и генерация: `node scripts/i18n/sync.mjs` сканирует оба клиента, пишет
`mobile/cleaning-ops-app/lib/core/i18n/translations.g.dart` и печатает, каких
переводов не хватает (`--check` падает, если есть пропуски; `--todo` печатает
пропуски в виде JSON для заполнения).
